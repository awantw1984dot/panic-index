# 特賣會儀表板

股市下殺是特賣會的開始，但要等人潮散去再進場。
美股、台股分開計算恐慌程度，每日兩次更新，狀態改變時透過 iPhone 捷徑通知。

## 區間名稱

| 分數 | 名稱 | 意思 |
|---|---|---|
| 0–20 | 漲價中 | 東西都很貴，別追 |
| 20–60 | 原價 | 照平常紀律 |
| 60–80 | 開始打折 | 準備購物清單，先不出手 |
| 80–100 | 特賣會 | 人潮洶湧，別擠第一波 |
| 退潮訊號觸發 | 可以進場搶購 | 分批買進 |

## 規格

**美股（怎麼看）**
- 信用 40%：HY 利差、IG 利差、JNK/IEF
- 股市波動 35%：VIX、VIX/VIX3M 期限結構
- 債市波動 25%：MOVE
- 交叉驗證（不計分）：STLFSI 金融壓力指數

**台股（怎麼做）**
- 臺指 VIX、融資維持率與融資 10 日變化、外資期貨空單變化、市場寬度

**四格狀態**：正常環境／本土事件／預警／系統性恐慌（≥60 視為恐慌側）

**更新**：每天台北 07:30、21:30 各跑一次，美股、台股都會增量更新

**流程**：GitHub Actions 計算 → 網頁＋資料檔 → iPhone 捷徑定時檢查並通知

**股災回放**：選擇事件逐日檢視儀表板當時的顯示，只用當天以前的資料計算
